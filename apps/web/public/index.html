    如何使用

    1. 先查看运行模式，确认查询使用的是样例图谱还是课程 Neo4j。
    2. 输入带有具体服务或方法名的问题；遇到同名实体时，选择候选项继续。
    3. 对照数据、Cypher 与关系路径核验答案。空结果、查询失败与结果截断会分别标记。
    4. 知识库里的“已验证”只代表在标记的图谱版本上执行并得到非空结果，仍需人工核对问题语义。
    5. 样例模式与规则生成用于开发联调，其通过率不能作为模型或课程独立评测结果。实际运行器和 Skill 版本见当前配置。
