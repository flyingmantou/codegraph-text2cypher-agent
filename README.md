# 面向代码图谱的 Text2Cypher 查询智能体

高级软件工程课程项目。面向 Train Ticket 微服务系统的已有 Neo4j 代码图谱，将自然语言问题转换为 Cypher 查询，支持代码关系理解、跨服务依赖分析和变更影响分析。

**当前状态：项目初始化。** 以下内容为开发计划，尚未完成实现与验收。拟采用 DeepSeek Harness、DeepSeek API 和 TypeScript，具体接口与版本将在接入验证后确定。

## 项目目标

- **T1 端到端查询**：获取真实 Schema，结合实体与示例生成 Cypher，完成校验、受控执行和结果整理。
- **T2 查询知识库**：建设至少 30 组经过目标图谱执行验证的自然语言—Cypher 示例，支持分类维护与检索。
- **T3 复杂查询**：支持下游服务发现、反向影响、MQ 链路和 RPC＋MQ 联合分析，保留路径依据与通信类型。
- **用户交互**：提供单题与批量查询、子图展示、过程追溯及 Markdown 报告导出。

查询流程计划实施只读访问、超时、结果规模及有限纠错控制，并区分歧义、空结果、失败和部分成功。

## 开发阶段

1. 验证图谱、框架与模型接入，确定模块接口。
2. 打通一条真实问题的端到端查询。
3. 完成示例知识库、检索和运行控制。
4. 扩展复杂查询与交互功能。
5. 使用独立 30 题评测，记录正确率、执行成功率、耗时和调用成本。
6. 完善部署、项目报告与演示材料。

示例库、开发用例与最终评测集分开维护，最终评测题不进入示例检索库。

## 协作方式
